# Basket or basket holder for ultrasonic cleaner

This is a remix of [Ultrasonic cleaner tray for Bandelin Sonorex Rk31h by Zazzel](https://makerworld.com/en/models/1591610-ultrasonic-cleaner-tray-for-bandelin-sonorex-rk31h), the idea being to fix an issue and add customization options so that it can be used with a wider variety of ultrasonic cleaner models.

The issue I found is that when you change the width of the bottom plate, it doesn't increase the spacing between the upper hooks, so you can't actually adapt it to cleaners with a different overall width.

My motivation for this work is that I wanted a tray that I can suspend in my Vevor 6 litre ultrasonic cleaner, but the result is that the design can be used with a variety of cleaners.
