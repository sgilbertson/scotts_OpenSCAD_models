# Simple replacement foot that I used for a Rubbermaid 1-Step step stool

This is a parametric design for a simple pad with treads, which can be affixed using glue or double-sided tape.

My use-case was replacement of the feet on a Rubbermaid 1-Step step stool, which I attached using outdoor carpet tape.

I have published this design on MakerWorld: [makerworld.com/en/models/3181321-parametric-foot-pad-with-tread-type-configuration](https://makerworld.com/en/models/3181321-parametric-foot-pad-with-tread-type-configuration)
