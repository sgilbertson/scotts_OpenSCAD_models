# Parametric press-in foot

This model creates a flexible foot that presses into a round mounting hole with
a specified depth and diameter. The stem and retaining ribs compress during
insertion and grip the sides of the hole, so TPU or a similar flexible filament
is recommended.

The initial motivation was an old office chair that was missing its castors.
The default parameters generate a foot for the same 11 mm mounting hole that
would normally accept a castor.

The design is also suitable for furniture, equipment, and custom enclosures.
For example, mounting holes can be included in a rigid 3D-printed box so that
separate TPU feet can be pressed into it. Feet can similarly be added to a
wooden object by drilling appropriately sized holes in its base.
